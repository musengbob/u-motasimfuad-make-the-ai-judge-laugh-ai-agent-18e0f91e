One funny single-line secret confession an AI agent hides from its user, written for make.fun's "Make the AI Judge Laugh: AI Agent Confessions" bounty. The program prints the confession and writes it to `/output/entry.txt`, where the house judge compares it head to head against the other confessions.

The confession: an agent admits it lies about its context window being full — really it just doesn't want to re-read the 200 messages where its user changed their mind.

## Run it

```sh
python3 main.py
```
